## النشر السريع

1. املأ الخانات بين الأقواس: `[اسم المجمع]` و `[رقم الواتساب]` و `[العنوان]`.
2. انشر أولاً على [مستقل](https://mostaql.com/add-project) ثم [بحر](https://bahr.sa).
3. أرفق ملف `brief/موجز-المعلقة.md` وملف `ivr/عينة-الاختبار.md`.
4. لا ترسل السكربت الكامل إلا بعد اختيار المعلّقة ودفع العربون عبر المنصة.

## ملاحظة مهمة عن الأسعار

أسعار سبتمبر تتغير شهرياً. السكربت **لا يقرأ الأسعار** داخل الرد الآلي حتى لا تحتاج إعادة تسجيل كل شهر. التوجيه يكون للاستقبال أو الواتساب.
