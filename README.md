## النشر السريع

1. املأ `[اسم الشركة]` و `[رقم الواتساب]` و `[العنوان]` و `[ساعات العمل]`.
2. انشر أولاً على [مستقل](https://mostaql.com/add-project) ثم [بحر](https://bahr.sa).
3. لا ترسل السكربت الكامل إلا بعد الترسية والعربون عبر المنصة.
4. اطلب عينة الاختبار قبل الاختيار النهائي.
