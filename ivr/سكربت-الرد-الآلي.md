# سكربت نظام الرد الآلي (IVR)

بدّل `[اسم الشركة]` و `[ساعات العمل]` و `[العنوان]` و `[رقم الواتساب]` قبل إرسال الملف للمعلّقة.

عدّل أسماء الأقسام في القائمة الرئيسية حسب نشاطك (مبيعات، دعم، حسابات، حجز…).

**قاعدة الأرقام:** واحد، اثنين، ثلاثة، أربعة، خمسة، ستة، سبعة، ثمانية، تسعة، صفر، نجمة، مربّع.

---

## شجرة الاتصالات

```
ترحيب
└─ القائمة الرئيسية
   1  المبيعات / طلب جديد
   2  خدمة العملاء
   3  الحسابات أو الطلبات الحالية
   4  مواعيد العمل والموقع
   0  موظف الاستقبال
   *  إعادة القائمة
```

---

## 1) الدفعة التجريبية — سجّليها أولاً

| الكود | النص |
|---|---|
| IVR_WELCOME | أهلاً وسهلاً بكم في [اسم الشركة]. نسعد بخدمتكم. |
| IVR_MAIN_MENU | للمبيعات اضغط واحد. لخدمة العملاء اضغط اثنين. للحسابات والطلبات الحالية اضغط ثلاثة. لمواعيد العمل والموقع اضغط أربعة. للتحدث مع موظف الاستقبال اضغط صفر. لإعادة القائمة اضغط نجمة. |
| IVR_INVALID | عذراً، الخيار غير صحيح. حاول مرة أخرى. |
| IVR_TIMEOUT | لم يتم اختيار أي رقم. سيتم إعادة القائمة. |
| IVR_HOLD | دقيقة من فضلك، جاري تحويلك إلى الاستقبال. |
| IVR_QUEUE | جميع الموظفين مشغولون حالياً. يرجى الانتظار أو معاودة الاتصال بعد قليل. |
| IVR_THANKS | شكراً لاتصالك بـ [اسم الشركة]. نتمنى لك يوماً سعيداً. |
| IVR_CLOSED | عذراً، خارج أوقات العمل حالياً. [ساعات العمل]. يمكنك التواصل عبر الواتساب على رقم [رقم الواتساب]، أو معاودة الاتصال لاحقاً. |

بعد اعتماد هذه الثمانية، سجّلي بقية الملفات **بنفس النبرة والمسافة من المايك**.

---

## 2) رسائل عامة للنظام

| الكود | النص |
|---|---|
| IVR_PLEASE_WAIT | يرجى الانتظار لحظات. |
| IVR_TRANSFER_DEPT | جاري تحويلك إلى القسم المختص. |
| IVR_TRANSFER_FAIL | تعذر التحويل حالياً. يمكنك ترك رسالة بعد الإشارة، أو معاودة الاتصال. |
| IVR_VOICEMAIL | اترك رسالتك بعد الإشارة مع الاسم ورقم الجوال وسبب الاتصال. سنعاود التواصل معك في أقرب وقت. |
| IVR_REPEAT | لإعادة الاستماع اضغط نجمة. |
| IVR_BACK | للرجوع للقائمة السابقة اضغط صفر. |
| IVR_GOODBYE | تم إنهاء المكالمة. نشكرك على تواصلك معنا. |
| IVR_BUSY | الخط مشغول الآن. يرجى المحاولة بعد قليل. |
| IVR_HOLIDAY | الشركة مغلقة بمناسبة إجازة رسمية. يمكنك التواصل عبر الواتساب، أو معاودة الاتصال بعد انتهاء الإجازة. |

---

## 3) تأكيد اختيار القائمة الرئيسية

| الكود | النص |
|---|---|
| IVR_MAIN_1_CONFIRM | تم اختيار المبيعات. |
| IVR_MAIN_2_CONFIRM | تم اختيار خدمة العملاء. |
| IVR_MAIN_3_CONFIRM | تم اختيار الحسابات والطلبات. |
| IVR_MAIN_4_CONFIRM | تم اختيار مواعيد العمل والموقع. |
| IVR_MAIN_0_CONFIRM | جاري توصيلك بموظف الاستقبال. |

---

## 4) المبيعات

| الكود | النص |
|---|---|
| IVR_SALES_MENU | لطلب خدمة أو عرض سعر اضغط واحد. للتحدث مع قسم المبيعات اضغط اثنين. للرجوع اضغط صفر. |
| IVR_SALES_NEW | سيتم تحويلك إلى المبيعات. يرجى تجهيز اسمك ورقم جوالك وملخص الطلب. |
| IVR_SALES_WHATSAPP | يمكنك أيضاً مراسلتنا عبر الواتساب على رقم [رقم الواتساب]. |

---

## 5) خدمة العملاء

| الكود | النص |
|---|---|
| IVR_CS_MENU | للدعم الفني اضغط واحد. للشكاوى والملاحظات اضغط اثنين. للتحدث مع خدمة العملاء اضغط ثلاثة. للرجوع اضغط صفر. |
| IVR_CS_SUPPORT | جاري تحويلك إلى الدعم. |
| IVR_CS_COMPLAINT | جاري تحويلك لتسجيل ملاحظتك. نعتذر عن أي إزعاج، وسنعمل على مساعدتك. |

---

## 6) الحسابات والطلبات

| الكود | النص |
|---|---|
| IVR_ACC_MENU | لمتابعة طلب حالي اضغط واحد. للاستفسار عن فاتورة أو دفعة اضغط اثنين. للرجوع اضغط صفر. |
| IVR_ACC_ORDER | لمتابعة الطلب سيتم تحويلك إلى القسم المختص. يرجى تجهيز رقم الطلب أو رقم الجوال المسجّل. |
| IVR_ACC_BILLING | للاستفسار المالي سيتم تحويلك إلى الحسابات. |

---

## 7) مواعيد العمل والموقع

| الكود | النص |
|---|---|
| IVR_INFO_MENU | لمواعيد العمل اضغط واحد. للموقع اضغط اثنين. للتحدث مع الاستقبال اضغط تسعة. للرجوع اضغط صفر. |
| IVR_HOURS | مواعيد العمل: [ساعات العمل]. |
| IVR_LOCATION | موقعنا: [العنوان]. |

---

## 8) التحويل

| الكود | النص |
|---|---|
| IVR_XFER_RECEPTION | تحويلك إلى الاستقبال. |
| IVR_XFER_SALES | تحويلك إلى المبيعات. |
| IVR_XFER_CS | تحويلك إلى خدمة العملاء. |
| IVR_XFER_ACC | تحويلك إلى الحسابات. |

---

## 9) الإغلاق

| الكود | النص |
|---|---|
| IVR_END_HELP | هل تحتاج مساعدة أخرى؟ للقائمة الرئيسية اضغط واحد. لإنهاء المكالمة اضغط اثنين. |
| IVR_WISH | شكراً لتواصلك معنا. |
| IVR_RATE | لتقييم المكالمة: اضغط واحد إذا كانت الخدمة ممتازة، واثنين إذا كانت جيدة، وثلاثة إذا كانت تحتاج تحسيناً. |
