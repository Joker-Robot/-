# سكربت نظام الرد الآلي (IVR)

بدّلي `[اسم المجمع]` و `[ساعات العمل]` و `[العنوان]` و `[رقم الواتساب]` قبل إرسال الملف للمعلّقة.

**قاعدة الأرقام في كل القوائم:** واحد، اثنين، ثلاثة، أربعة، خمسة، ستة، سبعة، ثمانية، تسعة، صفر، نجمة، مربّع.

---

## شجرة الاتصالات

```
ترحيب
└─ القائمة الرئيسية
   1  الحجز والمواعيد
   │  1 موعد جديد
   │  2 تأكيد أو إلغاء
   │  3 متابعة علاج
   │  0 رجوع
   2  الأقسام والتخصصات
   │  1 الليزر
   │  │  1 نساء   2 رجال   0 رجوع
   │  2 الجلدية والتجميل
   │  3 الأسنان
   │  4 الباطنية والطب العام
   │  5 النساء والولادة
   │  6 الأطفال
   │  7 المسالك والذكورة
   │  8 تخصصات أخرى
   │  │  1 العيون  2 الأنف والأذن  3 النفسية  4 الأشعة  0 رجوع
   │  0 رجوع
   3  العروض
   │  1 الليزر  2 البشرة  3 الأسنان  4 الباقات والفحوصات  0 رجوع
   4  مواعيد العمل والموقع
   5  المختبر والأشعة
   0  موظفة الاستقبال
   *  إعادة القائمة
```

## 1) الدفعة التجريبية — سجّليها أولاً

| الكود | النص |
|---|---|
| IVR_WELCOME | أهلاً وسهلاً بكم في مجمع [اسم المجمع] الطبي. نسعد بخدمتكم. |
| IVR_MAIN_MENU | لحجز موعد اضغط واحد. لمعرفة الأقسام والتخصصات اضغط اثنين. للاطلاع على العروض اضغط ثلاثة. لمواعيد العمل والموقع اضغط أربعة. لخدمات المختبر والأشعة اضغط خمسة. للتحدث مع موظفة الاستقبال اضغط صفر. لإعادة القائمة اضغط نجمة. |
| IVR_INVALID | عذراً، الخيار غير صحيح. حاول مرة أخرى. |
| IVR_TIMEOUT | لم يتم اختيار أي رقم. سيتم إعادة القائمة. |
| IVR_HOLD | دقيقة من فضلك، جاري تحويلك إلى موظفة الاستقبال. |
| IVR_QUEUE | جميع الموظفات مشغولات حالياً. يرجى الانتظار أو معاودة الاتصال بعد قليل. |
| IVR_THANKS | شكراً لاتصالك بمجمع [اسم المجمع] الطبي. نتمنى لك دوام الصحة والعافية. |
| IVR_CLOSED | عذراً، المجمع مغلق حالياً. [ساعات العمل]. يمكنك التواصل عبر الواتساب على رقم [رقم الواتساب]، أو معاودة الاتصال في وقت لاحق. |

بعد اعتماد هذه الثمانية، سجّلي بقية الملفات **بنفس النبرة والمسافة من المايك**.

| IVR_BEEP | *(صمت ثانية واحدة فقط — أو اتركي هذا الملف للنظام)* |
| IVR_REPEAT | لإعادة الاستماع اضغطي نجمة. |
| IVR_BACK | للرجوع للقائمة السابقة اضغطي صفر. |
| IVR_LANG_AR | للغة العربية اضغطي واحد. |
| IVR_GOODBYE | تم إنهاء المكالمة. نشكرك على تواصلك معنا. |
| IVR_BUSY | الخط مشغول الآن. يرجى المحاولة بعد قليل. |
| IVR_HOLIDAY | المجمع مغلق بمناسبة إجازة رسمية. يمكنك التواصل عبر الواتساب، أو زيارتنا بعد انتهاء الإجازة. |
| IVR_EMERGENCY | في الحالات الطارئة يرجى التوجه لأقرب إسعاف أو الاتصال بالطوارئ. هذا الخط لمواعيد العيادات والخدمات غير الإسعافية. |

## 5) قائمة الأقسام

| الكود | النص |
|---|---|
| IVR_DEPT_MENU | لقسم الليزر اضغطي واحد. لقسم الجلدية والتجميل اضغطي اثنين. لعيادة الأسنان اضغطي ثلاثة. للباطنية والطب العام اضغطي أربعة. للنساء والولادة اضغطي خمسة. لعيادة الأطفال اضغطي ستة. للمسالك البولية والذكورة اضغطي سبعة. للتخصصات الأخرى اضغطي ثمانية. للرجوع اضغطي صفر. |

|---|---|

## قائمة التسليم النهائية

المعلّقة تسلّم مجلدين:

```
ivr-master-48khz/     ← كل الأكواد أعلاه
ivr-pbx-8khz/         ← نفس الأسماء، نسخة السنترال
```

الملفات الاختيارية في القسم 11 توضع في مجلد فرعي `optional/` إذا لم تُطلب.

**عدد الملفات الأساسية (بدون اختياري الأطباء): 88 ملفاً.**
**مع القسم 11: 94 ملفاً.**
